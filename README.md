# Voy a jugar un juego específico: MAS Submod

Un SUBMOD para despedirte de Monika especificando el videojuego que jugarás.

<img src="./p1.jpg" width="100%">

# Instrucciones:

Selecciona: **Hablar** → **Adiós** → **Voy a jugar un juego específico**.

Escribe el juego que vas a jugar y listo.
